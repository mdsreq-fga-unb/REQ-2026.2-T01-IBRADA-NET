    Cronograma e Entregas

    Ciclo Período Objetivos Escopo Planejado Entregas Esperadas Atividades de ER e Validações Marcos Externos
    Ciclo 1 27/08 - 17/09 Levantamento inicial do cliente e negócio. Criação inicial e refinamento no documento de “Visão do Produto e Projeto”. - - Apresentação e validação do produto planejado ao cliente.
    - Entrega parcial do documento “Visão do Produto e Projeto”, de acordo com a Unidade 1.
    - Entendimento do negócio e necessidades dos stakeholders através da atividade de elicitação.    		 - E/D: Entrevista com os stakeholders de forma remota para entender as dificuldades atuais, modelos de atuação e expectativas do projeto.
    - A/C: Revisão da equipe da visão e do escopo do projeto definido.    		 Entrega da Unidade 1 (08/09/26)
    Ciclo 2 18/09 - 09/10 Definição do backlog do produto. - - Requisitos funcionais e não funcionais, MVP, critérios de aceitação (DoD e DoR) e backlog do produto definido.
    - Validação das características do produto (CPs).    		 - V/V, A/C, E/D: Entrevistas com os stakeholders para validação das características de produto, funcionalidades planejadas, MVP e Backlog do produto.
    - DC: Priorização - Matriz 2x2 de priorização (Equipe), incluindo MoSCoW para valor de negócio (Stakeholders).
    - O/A, DC: Rastreabilidade preliminar de requisitos (OE -> CP -> RF -> US).
    - V/V, DC: Critérios de aceitação para as características do produto.    		 -
    Ciclo 3
    (Incremento 1)    		 10/10 - 20/10 Planejamento técnico e visual do produto, preparação dos requisitos para implementação. - - Complemento ao documento “Visão do Produto e Projeto”, de acordo com a Unidade 2.
    - Preparação do ambiente de desenvolvimento (Next.js, MySQL, TypeScript).
    - Arquitetura de software definida.
    - Layout (design) do site definido.
    - Requisitos definidos para implementação do próximo ciclo.    		 - RP: Protótipos de baixa fidelidade do layout do site e esboços das principais funcionalidades (cadastro, login, catálogos etc.).
    - O/A, DC: Rastreabilidade atualizada.
    - V/V, A/C, E/D: Validação dos protótipos e funcionalidades com o cliente via vídeo chamada.    		 Entrega da Unidade 2 (13/10/26)
    Ciclo 4
    (Incremento 2)    		 21/10 - 31/10 Sistema de cadastro geral e ambiente para voluntários (CP4). RF08, RF09, RF10, RF11, RF18, RF21, RF22, RF23, RF25, RF26, RF26, RF29 Entrega parcial 1:
    - Definir perfis de acesso do sistema (gestor do IBRADA, apoiador, voluntário, cliente).
    - Ambiente reservado para voluntários, com sistema de perfil e inscrição para programas abertos.
    - Ambiente para gestão de voluntários (visualizar usuários inscritos em cada projeto, processo de seleção via filtro).
    - Sistema de notificações de novos projetos via email.
    - Requisitos definidos para implementação do próximo ciclo.    		 - RP: Protótipos do sistema de cadastro, ambiente de voluntários e sistema de filtragem para o processo seletivo.
    - V/V: Histórias de usuários para CP4 com checklist de critérios de aceitação de segurança.
    - V/V, DC: Testes de controle de acesso ao site, com evidências.
    - O/A, DC: Rastreabilidade atualizada.
    - V/V, A/C, E/D: Validação dos protótipos e funcionalidades com o cliente via vídeo chamada.    		 -
    Ciclo 5
    (Incremento 3)    		 01/11 - 11/11 Sistema de triagem de mensagens, módulo de gestão de voluntários e solicitação de parceria (CP2, CP4 e CP6). RF05, RF28, RF33, RF34 Entrega parcial 2:
    - Sistema de triagem para identificar o problema do usuário e direcioná-lo de acordo.
    - Sistema de solicitação de parcerias para apoiadores.
    - Sistema de gestão de seleção de voluntários com um funil.
    - Requisitos definidos para implementação do próximo ciclo.    		 - RP: Protótipos do sistema de triagem e solicitação de parceria, ambiente de gestão de voluntários.
    - V/V, DC: Testes.
    - V/V: Histórias de usuários para CP2, CP4 e CP6 com checklist de critérios de aceitação de segurança.
    - O/A, DC: Rastreabilidade e documentação atualizada.
    - V/V, A/C, E/D: Validação dos protótipos e funcionalidades com o cliente via vídeo chamada.    		 -
    Ciclo 6
    (Incremento 4)    		 12/11 - 22/11 Catálogo de serviços de ecoturismo com módulo transacional (CP3). RF06, RF07, RF12, RF13, RF14, RF15, RF17 Entrega parcial 3:
    - Catálogo exibindo todos os pacotes de ecoturismo disponível no momento.
    - Módulo transicional que permite compra de pacotes de ecoturismo disponível direto do site.
    - Sistema de solicitação de parcerias para apoiadores.    		 - RP: Protótipos do sistema de ambiente de compra de pacotes de ecoturismo.
    - V/V, DC: Testes de segurança e confirmation de transações, com evidências.
    - V/V: Histórias de usuários para CP3 com checklist de critérios de aceitação de segurança.
    - O/A, DC: Rastreabilidade e documentação atualizada.
    - V/V, A/C, E/D: Validação dos protótipos e funcionalidades com o cliente via vídeo chamada.    		 Entrega da Unidade 3 (17/11/26)
    Ciclo 7
    (Fechamento)    		 23/11 - 10/12 Testes gerais e transição para a organização. - Entrega do Produto Mínimo Viável (MVP):
    - Transferência do produto para o site atual do IBRADA.
    - Treinamento dos coordenadores do sistema com manual de operação.
    - Definição de responsabilidade pela manutenção do sistema.    		 - V/V, A/C: Apresentação do produto desenvolvido para o cliente.
    - O/A: Transição operacional (cutover).    		 Entrega da Unidade 4 (01/12/26)
