## 2. Assuntos debatidos

* Debate entre abordagem Ágil puro versus Híbrida. A equipe decidiu pela **abordagem híbrida** por permitir a estabilização de requisitos bem definidos no início, mantendo a flexibilidade ágil para os requisitos instáveis.
* O ciclo de vida definido foi o **Iterativo e Incremental**.
* Quanto ao processo, o Scrum foi descartado devido à inviabilidade de manter a alta frequência de reuniões formais (como *dailies*) exigidas pela rotina dos membros.
* Escolha da stack de desenvolvimento Web focada em **Next.js** e **nest.js**.
* O cliente principal (Guilherme Sampaio) encontra-se em viagem a trabalho, estando disponível prioritariamente no período noturno e nos domingos.
* Uma reunião inicial de elicitação detalhada de requisitos com o cliente ficou de ser agendada para o domingo.
* Definida a duração estimada de **10 dias** para cada *ciclo*.
* O grupo organizou os prazos para finalizar a escrita do documento até domingo, reservando a segunda-feira para revisão conjunta.
