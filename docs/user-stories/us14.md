## História de usuário

> Como visitante da plataforma, quero visualizar as informações detalhadas de uma oportunidade de voluntariado selecionada, para conhecer o projeto associado, a duração, a disponibilidade e as habilidades requeridas.

## Critérios de aceitação

- [ ] A página de cada oportunidade deve conter todas as informações sobre a atividade de voluntariado (projeto associado, atividades planejadas, duração, disponibilidade, local de atuação e habilidades requeridas).
- [ ] O sistema deve exibir uma opção para se candidatar, e bloqueá-la caso a oportunidade não esteja disponível ou não esteja aceitando candidatos.
- [ ] Se o visitante não estiver logado como voluntário, o botão deve redirecioná-lo ao fluxo de autenticação/cadastro (US15/US17), preservando o redirecionamento de volta para a vaga.

*Fonte: [issue #41](https://github.com/mdsreq-fga-unb/REQ-2026.2-T01-IBRADA-NET/issues/41).*
