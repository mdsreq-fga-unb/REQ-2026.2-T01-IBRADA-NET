## História de usuário

> Como usuário em processo de cadastro, quero consultar e aceitar explicitamente o termo de uso de dados pessoais, para decidir de forma consciente sobre o tratamento das minhas informações.

## Critérios de aceitação

- [ ] Durante o cadastro, o sistema deve exibir uma opção para ver os termos de uso de dados pessoais.
- [ ] O sistema deve permitir que o usuário aceite explicitamente os termos de uso de dados pessoais durante o cadastro e registrar data, hora e versão do termo aceito, conforme RF29.
- [ ] O sistema deve bloquear o cadastro de uma nova conta caso os termos de uso de dados pessoais não sejam aceitos.

*Fonte: [issue #48](https://github.com/mdsreq-fga-unb/REQ-2026.2-T01-IBRADA-NET/issues/48). Critérios complementados na documentação conforme RF29 (aceite explícito e registro de data, hora e versão do termo); a atualização da Issue permanece pendente.*
